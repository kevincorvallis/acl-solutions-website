2. Description of Service

Wilco is an AI-powered aviation radio communication trainer that provides simulated air traffic control (ATC) interactions. The App includes:

  • 20 training scenarios across taxi, departure, en-route, and approach phases
  • AI-generated ATC responses using GPT-4
  • ICAO standard phraseology validation and feedback
  • Voice input via Web Speech API and TTS output via ElevenLabs
  • Live METAR and TAF weather data integration
  • Performance tracking and improvement analytics
  • Three difficulty levels: Student, Private Pilot, and Advanced
